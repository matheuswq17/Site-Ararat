# ARARAT Sinal v1.0 — cópias para o site (experimento `experiment/brand-sinal-v1`)

Arquivos copiados **sem alteração** do pacote `ARARAT_Sinal_Brand_System_v1.0` (originais preservados em
`C:\ARARAT-Website\brand-system-sinal`). Uso, origem, tamanho e SHA-256 de cada um em `MANIFESTO.json`;
conferência: `node tests/sinal-integridade.mjs` (com `BASE=…`, também os bytes servidos).

- `logo/`: lockup horizontal escuro **full** (rodapé, ≥ 40 px) e **compacto** (cabeçalho, < 40 px). O wordmark
  é sempre o SVG em curvas.
- `favicon/`: favicon 16/32 (SVG e `.ico`) e ícones de app 180/512 px.
- `fontes/`: Geist (variável), Geist Mono 400/500 e licença OFL. A Geist Pixel Square não é usada.
- `icones/`: três ícones (`currentColor`), usados só onde o conceito corresponde ao conteúdo.
- `grafismos/`: campo de voxels e histograma. São grafismos conceituais, não dados.

O brand system ainda não foi validado com radiologistas. Nada aqui é evidência de funcionalidade clínica.
